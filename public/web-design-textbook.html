Introduction

ウェブを構成する言語と技術

ウェブサイトは複数の言語・技術の組み合わせで成り立っています。それぞれの役割と「何ができるか」を理解することが、ウェブデザイン学習の第一歩です。

フロントエンド（ブラウザ側）の3本柱

HTML
構造・コンテンツ

ウェブページの骨格を定義する言語。見出し、段落、画像、リンクなどの要素を記述し、コンテンツに「意味」を与えます。

  • 見出し・段落・リストなどの文書構造を定義する
  • 画像・動画・音声などのメディアを埋め込む
  • ハイパーリンクでページ間を結ぶ
  • フォーム（入力欄・ボタン）でユーザー入力を受け取る
  • テーブルで表形式のデータを表示する
  • セマンティックタグ（header, nav, main, footer）でアクセシビリティを向上させる
CSS
見た目・レイアウト

ウェブページの見た目を制御する言語。色、フォント、配置、アニメーションなど、ビジュアルデザインのすべてを担当します。

  • 色・フォント・文字サイズなどのスタイリング
  • Flexbox / CSS Grid による柔軟なレイアウト
  • レスポンシブデザイン（メディアクエリで画面サイズに対応）
  • アニメーション・トランジションで動きを演出
  • カスタムプロパティ（変数）でデザイントークンを管理
  • 疑似クラス（:hover, :focus）でインタラクティブなスタイルを定義
JavaScript
動作・インタラクション

ウェブページに動きと対話性を加えるプログラミング言語。ユーザー操作への反応やデータの動的な処理を実現します。

  • ボタンクリック・スクロールなどのイベント処理
  • DOM操作でHTMLの内容を動的に変更
  • カルーセル・モーダル・タブなどのUIコンポーネント実装
  • フォームのバリデーション（入力チェック）
  • API通信でサーバーからデータを取得・送信（fetch / Ajax）
  • ローカルストレージでブラウザにデータを保存

さらに広がるウェブ技術

TypeScript
型付きJavaScript

JavaScriptに型システムを追加した上位互換言語。大規模開発でのバグ防止やコードの可読性向上に役立ちます。

  • JavaScriptのすべての機能 + 静的型チェック
  • インターフェース・型定義でコードの意図を明確化
  • エディタの自動補完・リファクタリング支援を強化
  • React / Vue / Angular などのフレームワークと統合
PHP
サーバーサイド言語

サーバー側で動作する言語。WordPress（世界のWebサイトの約40%）の開発言語として広く使われています。

  • データベース（MySQL等）と連携しデータを読み書き
  • ユーザー認証・セッション管理
  • WordPressテーマ・プラグインの開発
  • お問い合わせフォームのメール送信処理
Python
バックエンド / AI

シンプルな文法で人気の汎用言語。ウェブのバックエンド開発のほか、データ分析やAI分野でも広く活用されています。

  • Django / Flask でウェブアプリケーションのバックエンド開発
  • REST API の構築でフロントエンドにデータを提供
  • データ分析・機械学習との連携
  • スクレイピング（ウェブ情報の自動収集）
Ruby
バックエンド / Rails

「プログラマーを幸せにする」をコンセプトに設計された言語。Ruby on Railsフレームワークでウェブアプリを高速開発できます。

  • Ruby on Rails でウェブアプリをすばやく構築
  • REST API / GraphQL API のバックエンド開発
  • ブログ・ECサイト・SNSなどのサービス開発
  • Shopify などECプラットフォームのプラグイン開発
Go（Golang）
高性能バックエンド

Googleが開発した高速・シンプルな言語。並行処理が得意で、大規模なウェブサービスのAPIサーバーに使われています。

  • 高速な REST API・マイクロサービスの開発
  • 大量リクエストを低コストで処理（並行処理）
  • CLIツールやDevOpsツールの開発
  • Docker・Kubernetes など主要OSS の多くがGoで書かれている
Java
エンタープライズ / Android

長年にわたり企業システムで使われてきた信頼性の高い言語。Spring Bootでのウェブ開発、Androidアプリ開発にも使われます。

  • Spring Boot で大規模ウェブアプリケーション開発
  • 銀行・官公庁など信頼性が求められるシステム構築
  • Android アプリ開発（Kotlinと並んで使用）
  • JVM上で動くため環境を問わず動作する（WORA）
SQL
データベース操作

データベースを操作するための問い合わせ言語。MySQL・PostgreSQL・SQLiteなど多くのデータベースで共通して使われます。

  • SELECT でデータを検索・抽出する
  • INSERT / UPDATE / DELETE でデータを操作する
  • ユーザー情報・商品情報などをテーブルで管理
  • JOIN で複数テーブルを結合して複雑な検索を行う
Sass / SCSS
CSSプリプロセッサ

CSSを拡張したメタ言語。変数・ネスト・ミックスイン・継承などの機能を追加し、大規模CSSの保守性を大幅に向上させます。

  • 変数（$color）で色・サイズを一元管理
  • ネストで要素の親子関係をそのまま記述できる
  • ミックスイン（@mixin）でスタイルを再利用
  • ファイル分割（@use/@forward）でCSSを整理
Rust
高性能 / WebAssembly

メモリ安全性と最高レベルのパフォーマンスを両立する言語。WebAssembly（Wasm）を通じてブラウザ上でも高速処理が可能です。

  • WebAssembly にコンパイルしてブラウザで超高速処理
  • ゲーム・画像処理・暗号処理などの高負荷計算
  • CLIツール・OSレベルのシステム開発
  • Figma の描画エンジンにも採用されている

言語の関係性

💡 ポイント 本テキストでは主にフロントエンドの3言語（HTML / CSS / JavaScript）を扱います。デザインの実装に必要な知識はこの3つで十分ですが、サーバーサイド言語の役割を知っておくと、チーム開発での全体像が把握しやすくなります。
Chapter 01

デザインの基礎原則

ロビン・ウィリアムズの「ノンデザイナーズ・デザインブック」で提唱された4大原則を中心に、ウェブデザインの土台となる考え方を学びます。

🎯 この章の学習目標

  1. デザインの4大原則（近接・整列・反復・コントラスト）を説明できる
  2. 視覚的階層の概念を理解し、実際のレイアウトに適用できる
  3. 余白（ホワイトスペース）の役割を理解し、8の倍数ルールを使える
  4. 良いデザインと悪いデザインの違いを論理的に説明できる

1-1. デザインの4大原則（C.R.A.P.）

📌

近接（Proximity）

関連する要素同士を近づけ、関連しない要素は離すことで、情報のグループを視覚的に伝えます。

📏

整列（Alignment）

すべての要素に視覚的なつながりを持たせます。要素を意図的に配置し、見えない線で結びます。

🔄

反復（Repetition）

色、フォント、形状などのデザイン要素を繰り返し使い、一貫性と統一感を生み出します。

⚡

コントラスト（Contrast）

異なる要素間に明確な差異を設けることで、視覚的な興味を引き、情報の階層を作ります。

1-2. 近接の原則 - 視覚的図解

左側は要素がバラバラに配置された例、右側は関連要素がグループ化された例です。

1-3. 視覚的階層（Visual Hierarchy）

ユーザーの視線を誘導し、最も重要な情報から順に伝えるためのテクニックです。

💡
デザインのコツ視覚的階層をテストする簡単な方法は「目を細めてデザインを見る」こと。ぼやけた状態でも情報の重要度が伝わるなら、階層設計は成功しています。

1-4. 余白（ホワイトスペース）の力

余白は「何もない空間」ではなく、デザインの重要な構成要素です。適切な余白はコンテンツの可読性を高め、洗練された印象を与えます。

✅ 第1章のまとめ

  • 近接: 関連する要素をまとめ、無関係な要素を離す
  • 整列: すべての要素を見えない線で結び、秩序を与える
  • 反復: スタイルを統一し、一貫性のあるデザインを構築する
  • コントラスト: 差異を明確にし、視覚的な階層を作る
  • 余白: 空間を戦略的に使い、可読性と洗練さを高める
Chapter 02

タイポグラフィ & カラー

テキストと色はウェブデザインの大部分を占めます。適切なフォント選びと配色は、デザインの品質を決定的に左右します。

🎯 この章の学習目標

  1. セリフ体・サンセリフ体・モノスペース体の違いと適切な使い分けを説明できる
  2. Modular Scale を用いたフォントサイズ体系を設計できる
  3. 色相環を使い、補色・類似色・トライアドの配色パターンを作成できる
  4. 60-30-10 ルールに基づいた配色をウェブサイトに適用できる

特徴FlexboxCSS Grid
方向1次元（行 or 列）2次元（行 x 列）
向きコンテンツ起点レイアウト起点

4-2. カルーセル（Carousel / Slider）

🎨 デザイン思考

ユーザー中心のデザインプロセスを大切にしましょう。共感 → 定義 → 発想 → プロトタイプ → テスト のサイクルを回すことで、より良いデザインが生まれます。

♿ アクセシビリティ

5-4. スクロールアニメーション

このテキスト自体に適用されている「スクロールで要素がフェードイン」する効果のコード例です。

CSS + JS /* CSS: 初期状態 */ .reveal { opacity: 0; transform: translateY(30px); transition: opacity .6s, transform .6s; } .reveal.visible { opacity: 1; transform: translateY(0); } // JS: IntersectionObserver で検知 const obs = new IntersectionObserver(entries => { entries.forEach(e => { if (e.isIntersecting) e.target.classList.add('visible'); }); }, { threshold: 0.1 }); document.querySelectorAll('.reveal') .forEach(el => obs.observe(el));
⚠️
アニメーション使用時の注意 • prefers-reduced-motion でアニメーション無効化オプションを提供する
• 1秒以上のアニメーションはストレスを与える可能性がある
• transform と opacity は高パフォーマンス（GPU対応）

✅ 第5章のまとめ

  • @keyframes でアニメーションのステップを定義し、animation プロパティで適用する
  • トランジションは状態変化（hover等）時に使い、アニメーションは自動再生やループに使う
  • ease は自然な動き、linear は等速、ease-out は減速で終わり自然に感じやすい
  • transform と opacity はGPUアクセラレーション対応でパフォーマンスが高い
  • prefers-reduced-motion への対応はアクセシビリティの必須事項

Appendix

用語集（Glossary）

本テキストに登場する主要な専門用語の定義を五十音順にまとめています。

アクセシビリティ（A11y）
障害の有無にかかわらず、すべてのユーザーがウェブコンテンツを利用できるようにすること。WCAG が国際基準。
イージング（Easing）
アニメーションの速度変化を制御する関数。ease, linear, ease-in-out などがある。
インラインとブロック
HTMLの表示モード。ブロック要素（div, p）は改行を伴い幅いっぱいに広がり、インライン要素（span, a）はテキストの流れの中に配置される。
ウェブフォント（Web Font）
サーバーからフォントデータを配信し、閲覧者の端末にないフォントでも表示可能にする技術。Google Fonts が代表的。
カルーセル（Carousel）
複数のコンテンツをスライド形式で順番に表示するUIコンポーネント。スライダーとも呼ぶ。
カスタムプロパティ（CSS変数）
--primary-color のように定義し、var() で参照するCSSの変数機能。デザイントークンの管理に必須。
グリッドシステム（Grid System）
ページを均等な列に分割し、要素を整然と配置するためのレイアウト手法。12カラムが標準的。
コントラスト比（Contrast Ratio）
前景色と背景色の明るさの比率。WCAG では通常テキストに4.5:1以上を要求。
色相環（Color Wheel）
色相を円環状に配置した図。補色（対角）、類似色（隣接）、トライアド（三等分）などの配色パターンの基礎。
CLS（Cumulative Layout Shift）
ページ読み込み中の予期しないレイアウトのずれを測る Core Web Vitals 指標。0.1以下が良好。
セマンティックHTML
要素の意味（見出し、ナビ、記事等）を正しく伝えるHTMLタグの使用。SEOとアクセシビリティに直結。
セレクタ（CSS Selector）
CSSでスタイルを適用する対象を指定する記法。要素型、クラス（.class）、ID（#id）、属性、疑似クラスなどがある。
タブ（Tabs）
複数のコンテンツパネルをタブで切り替えて表示するUIパターン。限られたスペースに多くの情報を整理できる。
デザインカンプ（Design Comp）
実装前に作成するウェブページの完成イメージ。Figma等のツールで制作し、デザインの最終確認に使う。
デザイントークン（Design Token）
色・フォントサイズ・余白などのデザイン値を一元管理する仕組み。CSS変数やJSON形式で定義し、チーム全体で統一する。
トランジション（Transition）
CSSプロパティの値が変化する際に、滑らかな遷移効果を適用する仕組み。
ナビゲーション（Navigation）
ウェブサイト内のページ間移動を案内するUI。ヘッダーナビ、サイドバー、パンくずリスト、フッターナビなどの種類がある。
パンくずリスト（Breadcrumb）
ホーム > カテゴリ > ページ のように、現在位置をサイト階層で示すナビゲーション。SEOにも有効。
ビューポート（Viewport）
ブラウザの表示領域。<meta name="viewport"> タグでモバイルでの表示制御を行い、レスポンシブデザインの基盤となる。
Flexbox
CSSの1次元レイアウトモデル。要素を横方向または縦方向に柔軟に配置。ナビバーやカードの整列に最適。
フレームワーク（Framework）
開発の枠組みを提供するソフトウェア。CSSフレームワーク（Bootstrap, Tailwind）やJSフレームワーク（React, Vue）がある。
ブラウザDevTools
ブラウザ内蔵の開発者ツール。HTML/CSS/JSの検証、レスポンシブテスト、パフォーマンス計測が可能。F12キーで起動。
ブレイクポイント（Breakpoint）
レスポンシブデザインでレイアウトを切り替える画面幅の境界値。一般的に768px（タブレット）、1024px（デスクトップ）など。
ホワイトスペース（White Space）
要素間の余白。「何もない空間」ではなく、可読性と視覚的階層を高めるデザイン要素。
ボックスモデル（Box Model）
すべてのHTML要素が持つ、content → padding → border → margin の4層構造。要素のサイズ計算の基本。
マイクロインタラクション
ボタンのホバー効果、いいねのアニメーションなど、小さな動きでフィードバックを返すUI演出。ユーザー体験を向上させる。
メディアクエリ（Media Query）
@media (min-width: 768px) のように条件を指定し、画面サイズや端末特性に応じたCSSを適用する仕組み。
モーダル（Modal）
背景を暗くし、ユーザーの注意を特定のコンテンツに集中させるオーバーレイ型のダイアログ。
モバイルファースト
まずモバイル向けにデザイン・実装し、画面幅の拡大に応じて拡張していく設計手法。
Modular Scale
一定の比率（例: 1.25倍）でフォントサイズを決定する手法。調和のとれたタイポグラフィを実現。
ユーザビリティ（Usability）
ウェブサイトの使いやすさ。直感的なナビゲーション、明確なCTA、一貫したデザインがユーザビリティを高める。
ラテラルナビゲーション
同じ階層のページ間を横方向に移動するナビゲーション。タブやページネーションが代表例。
レスポンシブデザイン
1つのHTMLで、画面サイズに応じて最適なレイアウトに変化するデザイン手法。
ワイヤーフレーム（Wireframe）
ウェブページの構造・配置を線と箱で簡略化した設計図。ビジュアルデザインの前段階で情報設計を検討するために使う。
altテキスト（代替テキスト）
画像に設定するテキスト説明。画像が表示できない場合やスクリーンリーダーで読み上げられ、アクセシビリティの必須要素。
CTA（Call To Action）
「購入する」「無料で始める」などユーザーに行動を促すボタンやリンク。デザインでは目立つ色・配置で視線を誘導する。
DOM（Document Object Model）
HTMLをツリー構造のオブジェクトとして表現したもの。JavaScriptからDOMを操作してページ内容を動的に変更できる。
INP（Interaction to Next Paint）
ユーザー操作から次の描画までの遅延を測る Core Web Vitals 指標。200ms以下が良好。FID の後継。
LCP（Largest Contentful Paint）
ページ内の最大コンテンツが表示されるまでの時間。Core Web Vitals 指標で2.5秒以内が良好。
SEO（検索エンジン最適化）
検索結果で上位表示されるよう、サイト構造・コンテンツ・パフォーマンスを最適化する施策。セマンティックHTMLが基盤。
SVG（Scalable Vector Graphics）
XMLベースのベクター画像形式。拡大しても劣化せず、CSSやJSで操作可能。アイコンやロゴに最適。
UI / UX
UI（User Interface）はユーザーとの接点のデザイン。UX（User Experience）はサイト利用を通じた総合的な体験。UIはUXの一部。
WCAG（Web Content Accessibility Guidelines）
W3Cが策定するウェブアクセシビリティの国際ガイドライン。レベルA, AA, AAAの3段階。
WebP / AVIF
次世代の画像フォーマット。JPEGやPNGより高圧縮・高品質で、ページ読み込み速度の改善に貢献する。
z-index
CSS要素の重なり順（前後関係）を制御するプロパティ。モーダルやドロップダウンなど、他の要素の上に表示する場合に使用。
