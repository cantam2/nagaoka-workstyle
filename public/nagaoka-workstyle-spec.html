Chapter 1

プロジェクト概要

1.1 システム概要

「長岡ワークスタイル」は、新潟県長岡市における就職・採用情報を提供するポータルサイトです。地元企業の求人情報・インターンシップ情報・職場の雰囲気を、動画や記事コンテンツとともに発信し、求職者と企業のマッチングを支援します。

本サイトは全6ページのフロントエンド実装（HTML / CSS / Vanilla JavaScript）で構成されており、外部フレームワークへの依存なしに動作します。

技術スタック
  • HTML5 / CSS3（カスタムプロパティ使用）
  • Vanilla JavaScript（ライブラリ不使用）
  • Google Fonts（Noto Sans JP / Montserrat）
  • Unsplash（バナー・サムネイル画像ホットリンク）
  • localStorage（ターゲットユーザー設定の永続化）

1.2 対象ユーザーとターゲット区分

サイト全体は3種類のターゲットユーザー区分を持ちます。ユーザーがゲートウェイページで選択した区分は localStorage に保存され、各ページの表示コンテンツの切り替えに利用されます。

区分キー 対象ユーザー アクセントカラー 表示クラス

tr転職・UIターン希望者#e8841a（オレンジ）.for-tr
ntr新卒＋転職（高校生以外）—.for-ntr

2.3 共通コンポーネント

スティッキーヘッダー

全ページ共通。ロゴ・ナビゲーションリンク・ターゲット切り替えボタン・応募/お気に入りボタンを含む。スクロール追従（position: sticky; top: 0）。

タブコンポーネント（.program-tabs-wrapper）

インターンシップセクションおよび募集中の職種セクションで使用。タブバー＋パネルの構成で、switchProgram() JS関数によってパネルを切り替える。

タブデザイン仕様
  • タブバー背景：グラデーション（#ddf0f7 → #c8e6f2）
  • 非選択タブ：半透明白背景（rgba(255,255,255,0.55)）・角丸8px
  • 選択中タブ：プライマリーカラー塗りつぶし・白文字・ドロップシャドウ
  • カード全体：白背景・角丸16px・シャドウ・シアン枠線

カルーセルコンポーネント

動画カルーセルおよび記事カードカルーセルで使用。scroll-snap-type: x mandatory + overflow-x: autoによる横スクロール。左右に重なり矢印ボタン（.carousel-arrow）を配置。

モーダルダイアログ

応募フォーム・見学申込フォームをモーダルで表示。openModal() / closeModal() JS関数で制御。

2.4 ターゲット別表示制御

CSSクラスとJavaScriptによって、ターゲットユーザーに応じたコンテンツの表示・非表示を制御します。

CSSクラス表示条件用途例
.for-hsbody.target-hs のとき表示高校生向け工場見学情報・バッジ
.for-ncbody.target-nc のとき表示新卒向けインターンシップ・採用情報
.for-trbody.target-tr のとき表示転職者向けカジュアル面談・年収情報
.for-ntrnc または tr のとき表示応募ボタン・選考フロー

JavaScriptは localStorage.getItem('nagaoka_target') の値に応じて document.body.classList に該当クラスを付与します。

6.3 募集中の職種（タブ形式）

機能概要

タブラベル仕様

職種タブラベル（Indeed風）

パネル内構成（上から順）

  3. .job-title-row：雇用形態バッジ（正社員）＋職種名
  4. .job-meta：月給 ・勤務地
  5. .job-detail-grid：仕事内容 / 勤務時間 / 応募資格 / 求める人材（2列グリッド）

8.2 HTML内部構造

各HTMLファイルはCSS・JavaScriptをすべてインラインで記述するシングルファイル構成です（外部CSSファイル・外部JSファイルなし）。Google FontsのみCDN経由で読み込みます。

各HTMLファイルの構成順序
  1. <head> — meta / Google Fonts / <style>（全CSS）
  2. <header> — スティッキーヘッダー（共通）
  3. ページ固有のセクション群
  4. モーダルダイアログ（応募・見学申込）
  5. <script>（全JavaScript）
